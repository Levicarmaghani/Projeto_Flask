🧾 Sistema de Controle de Dias Trabalhados — Flask

Um sistema simples e funcional para registrar dias trabalhados, valores recebidos e salvar tudo em arquivos .txt.
O objetivo do projeto é demonstrar conhecimentos em:

Python

Flask (back-end)

HTML + Bootstrap (front-end)

Manipulação de arquivos

Rotas e templates no Flask

Organização de projeto web

Este projeto foi criado como parte da minha evolução em desenvolvimento web back-end.

🚀 Funcionalidades

📅 Registrar dias trabalhados

💰 Associar valores recebidos

💾 Salvar registros automaticamente em arquivos .txt

📂 Leitura dos dados já registrados

🖥️ Interface simples usando HTML + Bootstrap

🌐 Rotas Flask organizadas e fáceis de entender

🛠️ Tecnologias Utilizadas
Tecnologia	Uso
Python 3	Lógica e manipulação dos dados
Flask	Servidor web, rotas e templates
HTML5	Estrutura das páginas
Bootstrap 5	Estilização rápida e responsiva
Arquivos .txt	Armazenamento dos dados
